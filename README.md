# Central London Occupier Guide

Static GitHub Pages source for Lambert Smith Hampton's Central London Occupier Guide.

The landing page is carried over from `Central_London_Submarkets`. The first repository-native submarket dashboard is available at `submarkets/noho-fitzrovia/`; its content is driven by `data/submarkets/noho-fitzrovia.json` so the same structure can be reused for the remaining submarkets.

## Local preview

Serve the repository root with any static web server, then open `/` for the landing page or `/submarkets/noho-fitzrovia/` for the dashboard.
